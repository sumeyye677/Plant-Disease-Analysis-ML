# 🌿 Plant Health Analysis with Machine Learning

An end-to-end machine learning project focused on **plant species classification** and **health status prediction** using physical and chemical plant data.  
The project aims to support agricultural efficiency through data-driven analysis and automation.


## 🎯 Project Overview

This project was developed to interpret complex plant datasets and automate critical tasks such as **species identification** and **plant health classification**.

The application:
- 🧹 Cleans and preprocesses raw data for machine learning
- 🤖 Trains and compares multiple machine learning models
- 📊 Uses data visualization to explore feature relationships

---

## 🚀 Features & Analysis Scope

- 🔍 **Exploratory Data Analysis (EDA)**  
  Statistical distributions, missing value handling, and outlier detection

- 🛠️ **Feature Engineering**  
  Data normalization and categorical variable encoding

- 📈 **Model Evaluation**  
  Performance analysis using Accuracy, F1-Score, and Confusion Matrix

- 🎨 **Visual Reporting**  
  Analysis supported by heatmaps and distribution plots

---

## 🤖 Models and Evaluation Results

The following models were implemented and evaluated:

- Logistic Regression  
- K-Nearest Neighbors (KNN)  
- Decision Tree  
- Random Forest  
- MobileNet  

✅ **Final Result**  
All models were evaluated using Accuracy and F1-Score metrics.  
The **MobileNet** model achieved the highest accuracy and overall performance.
